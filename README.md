# gost-tool
https://github.com/ginuerzh/gost 的配置工具

## 使用
Used:
```
curl -sL https://raw.githubusercontent.com/Rczlin/gost-tool/refs/heads/main/gost-cli.sh -o gost-cli.sh && bash gost-cli.sh
```
IPV4
```
curl --ipv4 -sL https://raw.githubusercontent.com/Rczlin/gost-tool/refs/heads/main/gost-cli.sh -o gost-cli.sh && bash gost-cli.sh
```
IPV6
```
curl --ipv6 -sL https://raw.githubusercontent.com/Rczlin/gost-tool/refs/heads/main/gost-cli.sh -o gost-cli.sh && bash gost-cli.sh
```
